# BIKE RED PULL — Native Android Kotlin

Native Android OpenGL ES motorcycle highway game starter. The game scene is rendered in 3D with generated geometry; the app includes touch-and-hold acceleration, speed and RPM HUD, speed-based road appearance, a bike shop, coin persistence, pause and restart.

GitHub Actions builds Debug and Release APKs on every push to main and on manual workflow dispatch. Download them from Actions > workflow run > Artifacts.

The Release APK uses the standard debug signing key for testing only. It is not a Play Store signing setup.
